Privacy Policy

TubeShield by RatioJuris · Effective: 3 October 2026

Overview

TubeShield is a browser extension that provides local ad blocking and configurable site-blocking controls.

Data handling

TubeShield stores user preferences and local blocking statistics in the browser's extension storage. The extension does not include a server-side account system, analytics service, advertising SDK, or remote telemetry system.

The extension's declarative network rules are evaluated by the browser. TubeShield does not use a background server to receive or analyse users' browsing traffic.

Information stored locally

Depending on the features used, TubeShield may store:

  • blocked-site/domain entries configured by the user;
  • ad-blocking preference;
  • site-blocking preference; and
  • locally maintained blocking statistics and timestamps.

This information remains in the browser's extension storage unless the browser or user removes the extension data.

Network requests

TubeShield uses the browser's declarativeNetRequest API to apply blocking rules. The API allows the browser to block matching requests without the extension intercepting and reading their content.

Advertising-blocking operation

Supported advertising elements may be handled locally by the extension's content script. Locally detected blocking events may contribute to the statistics displayed by the extension.

These statistics are maintained locally and are not transmitted by TubeShield to a remote analytics service.

Blocked-site configuration

Users may configure domains or URL patterns through the Options page. When the blocked-sites feature is enabled, TubeShield creates browser-level blocking rules for the configured entries.

The number of configured site entries represents configured rules. It should not be interpreted as a count of network requests blocked by the browser.

Third-party services

TubeShield does not require an online account or a TubeShield server to provide its core blocking functionality.

The extension may operate on websites and network resources provided by third parties. Those third parties operate their own websites, services and privacy practices.

Security

TubeShield is designed to minimise unnecessary data handling by keeping extension preferences and locally generated statistics within browser extension storage.

No electronic system can be guaranteed to be completely secure. Users remain responsible for maintaining the security of their browser, operating system and device.

The revised policy will become effective when published on this website unless a different effective date is stated.
