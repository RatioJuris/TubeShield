Take back control of your video browsing.

TubeShield by RatioJuris provides browser-side ad blocking and configurable video-site and URL/domain blocking controls, with preferences and statistics maintained locally in the browser.

Version 1.0.0 · Manifest V3 · Designed for Chromium-based browsers

FEATURES

Simple controls. Browser-side operation.

TubeShield keeps its core configuration local and uses browser-native blocking mechanisms.

01

Ad blocking

Supported advertising elements can be hidden locally, with active video ads handled where the extension can detect them.

02

Custom site blocking

Add domains and URL patterns to a configurable blocked-sites list and enable whole-site navigation blocking when required.

03

Local settings

Extension preferences and locally maintained statistics are stored through browser extension storage.

04

Dynamic rules

Configurable site rules are implemented with the browser's Declarative Net Request API.

05

Options page

Manage blocking preferences, configured domains, defaults and local statistics from one dedicated page.

06

Open development

Review the source, report issues and follow development through the public RatioJuris GitHub repository.
